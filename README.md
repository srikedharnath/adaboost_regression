# adaboost_regression

# Video Game Sales Prediction using Machine Learning

## Overview

This project predicts Video Game Sales using Machine Learning Regression algorithms.

The application is developed using Python and Streamlit.

The model predicts sales values based on different video game features.

---

# Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

---

# Machine Learning Type

Regression

---

# Algorithms Used

- Linear Regression
- Random Forest Regressor
- AdaBoost Regressor

---

# Dataset

Dataset Name:

Video Game Sales Dataset

The dataset contains information about video games such as:

- Platform
- Genre
- Publisher
- Year
- Global Sales
- NA Sales
- EU Sales
- JP Sales

---

# Features Used

Some important features used in the project:

- Platform
- Genre
- Publisher
- Year
- Critic Score
- User Score

---

# Target Variable

- Global Sales

The model predicts the sales value of video games.
